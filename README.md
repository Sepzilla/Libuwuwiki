# Libuwuwiki - Homelab Wiki

Welcome to the Libuwuwiki! This wiki provides documentation for all services running in the homelab.

## 📚 Available Services

### Media Servers
- **[Plex](docs/plex.md)** - Stream your personal media collection with apps for every device
- **[Jellyfin](docs/jellyfin.md)** - Free and open-source media system with no subscription required

### Media Management
- **[Jellyseerr](docs/jellyseerr.md)** - Request and manage media for your Plex or Jellyfin server
- **[Audiobookshelf](docs/audiobookshelf.md)** - Self-hosted audiobook and podcast server

### E-Books & Reading
- **[Calibre](docs/calibre.md)** - E-book management and library system
- **[Calibre Downloader](docs/calibre-downloader.md)** - Automated e-book downloading and management

### Dashboard
- **[Heimdall](docs/heimdall.md)** - Application dashboard for quick access to all your services

## 🚀 Quick Start

1. Choose a service from the list above
2. Click on the service name to view its documentation
3. Follow the access instructions and feature guides

## 📖 About This Homelab

This homelab provides a self-hosted ecosystem for media streaming, e-book management, and service organization. All services are containerized and accessible through the local network.

## 🔗 Navigation

Each service documentation includes:
- Access instructions (URL, credentials, network requirements)
- Key features and capabilities
- Basic usage guide
- Tips and best practices
