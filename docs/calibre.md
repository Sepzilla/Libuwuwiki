# Calibre

Calibre is a powerful and easy-to-use e-book manager that lets you organize, convert, read, and share your digital book collection.

## 🔐 Access Instructions

### Web Interface (Calibre Content Server)
- **URL**: `https://books.libuwutawians.org`
- **Authentication**: Pangolin

### Desktop Application
- Install Calibre desktop application on your computer
- Connect to server library
- Full editing and management capabilities
### Mobile App
- Access via web browser on mobile devices
- Use Calibre Companion app (Android) for enhanced features
- Download books for offline reading in your preferred e-reader app

## ✨ Key Features

### Library Management
- **Unlimited Books**: Manage thousands of e-books in one place
- **Metadata Editing**: Comprehensive metadata management (title, author, tags, series, etc.)
- **Cover Management**: Download or upload custom book covers
- **Virtual Libraries**: Create filtered views of your library
- **Duplicate Detection**: Find and merge duplicate books

### Format Conversion
- **Wide Format Support**: Read and convert between 15+ e-book formats
- **Batch Conversion**: Convert multiple books simultaneously
- **Quality Preservation**: Maintains formatting and images during conversion
- **Custom Conversion**: Fine-tune conversion settings per format
- **Supported Formats**: EPUB, MOBI, AZW3, PDF, TXT, HTML, RTF, and more

### Reading & Viewing
- **Built-in Reader**: Read e-books directly in your browser
- **Full-Screen Mode**: Distraction-free reading experience
- **Customizable Display**: Adjust fonts, sizes, colors, and margins
- **Bookmark Support**: Save your reading position
- **Table of Contents**: Easy navigation through chapters

### Metadata Management
- **Auto-Fetch**: Download metadata from multiple online sources
- **Bulk Editing**: Edit multiple books at once
- **Custom Columns**: Add custom fields for personal organization
- **Search & Filter**: Powerful search with saved searches
- **Tags & Categories**: Organize with unlimited tags and categories

### Content Server Features
- **Remote Access**: Access your library from anywhere
- **User Accounts**: Multiple users with individual preferences
- **OPDS Catalog**: Compatible with many e-reader apps
- **Book Downloading**: Download in multiple formats
- **Browse Categories**: Filter by author, tag, series, publisher, etc.

## 📝 Basic Usage Guide

### Adding Books
1. **Via Web Interface**:
   - Click "Upload books" button
   - Select files from your device
   - Metadata will be auto-fetched
   
2. **Via Desktop App**:
   - Drag and drop files into Calibre
   - Click "Add books" and browse for files
   - Add entire folders at once

### Organizing Your Library
1. **Edit Metadata**:
   - Click on a book to open details
   - Click "Edit metadata" button
   - Update title, author, tags, series, etc.
   - Download metadata from online sources
   
2. **Add Tags**:
   - Select books
   - Add tags for genres, reading status, or custom categories
   - Use tags to filter and organize

3. **Series Management**:
   - Set series name and book number
   - Calibre will sort series automatically
   - Easy series browsing in the interface

### Converting E-Books
1. Select the book you want to convert
2. Click "Convert books" or right-click → Convert individually
3. Choose output format (EPUB, MOBI, PDF, etc.)
4. Adjust settings if needed (page setup, table of contents, etc.)
5. Click OK to start conversion
6. Converted book appears as additional format

### Reading Books
1. Click on a book cover or title
2. Click "Read book" button
3. Use navigation controls:
   - Arrow keys or swipe to turn pages
   - Click table of contents for navigation
   - Adjust settings (gear icon) for personalization
4. Bookmarks are saved automatically

### Searching & Filtering
- **Simple Search**: Type in search box for title/author
- **Advanced Search**: Use filters for specific criteria
- **Saved Searches**: Create virtual libraries with filters
- **Quick Filters**: Click on author, tag, or series to filter

## 💡 Tips & Best Practices

### Library Organization
- Use consistent tagging conventions (e.g., #read, #wishlist, #favorite)
- Set up virtual libraries for different reading lists
- Add custom columns for personal tracking (rating, location, etc.)
- Keep series information updated for better browsing

### Metadata Best Practices
- Always fetch metadata after adding books
- Review and correct auto-fetched data
- Add personal tags for genres not in metadata
- Include publisher and publication date when available
- Use identifiers (ISBN, Amazon ID) for better metadata matching

### Format Strategy
- Keep original format always
- Convert to EPUB for most e-readers (except Kindle)
- Convert to AZW3 or MOBI for Kindle devices
- Use EPUB for maximum compatibility
- Keep PDF only for fixed-layout books
### Performance Tips
- Store library on fast storage (SSD preferred)
- Enable metadata backup in preferences
- Limit cover size for faster loading
- Use virtual libraries instead of complex searches

## 🔧 Troubleshooting

### Books Not Importing
- Check file format is supported
- Verify file isn't corrupted (try opening in another app)
- Ensure sufficient disk space
- Check file permissions

### Metadata Not Found
- Verify internet connection
- Try alternative metadata sources
- Manually enter ISBN or identifier
- Search with different title/author variations

### Conversion Issues
- Check if input format is supported
- Try different output settings
- Update Calibre to latest version
- Some DRM-protected files cannot be converted

### Web Interface Not Accessible
- Verify server is running
- Check firewall allows port 8083
- Confirm correct IP address
- Try accessing from localhost first

### Reading Issues in Browser
- Clear browser cache
- Try different browser
- Check JavaScript is enabled
- Verify book format is web-compatible
